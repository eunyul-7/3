# 한밤의 사건 파일

브라우저에서 바로 플레이하는 텍스트 추리 게임입니다. `index.html`을 열면 시작됩니다. 빌드나 설치는 필요 없습니다.

## 사건

| 파일 | 사건 | 무대 |
| --- | --- | --- |
| ∞ | 무작위 사건 | 6가지 무대 중 하나에서 용의자·흔적·동기·수법·범인이 매번 새로 정해짐 |
| 01 | 청람장 사건 | 폭우 속 산장, 서재의 독살 |
| 02 | 달빛극장 사건 | 소극장 인터미션, 분장실 |
| 03 | 은하 야간열차 사건 | 침대열차의 밀실 |
| 04 | 한빛 박물관 사건 | 폐관 후 수장고에서 숨진 관장과 바꿔치기된 국보 |

## 규칙

- 시작 화면에서 탐정 이름을 정합니다. 이름은 브라우저에 저장됩니다.
- **난이도**: 01번 사건은 쉬움, 02번은 보통, 03·04번은 어려움으로 시작합니다. 무작위 사건은 푼 횟수에 따라 올라갑니다. 사건을 열 때 직접 바꿀 수도 있습니다.
- **시간 제한 모드**: 실제 시계가 흐릅니다(쉬움 12분, 보통 9분, 어려움 6분). 시간이 다 되면 턴이 남아도 경찰이 도착합니다. 보통·어려움에서 기본으로 켜집니다.
- 장소 조사·심문 한 번에 1턴이 지나고, 턴이 다 떨어지면 경찰이 도착합니다.
- 단서를 찾으면 용의자에게 새 질문이 열립니다.
- **모순 지적**: 들은 진술에 단서를 들이밀 수 있습니다. 맞으면 진술이 번복되고, 틀리면 1턴을 잃습니다.
- **훼방**: 쉬움에서는 없고, 보통·어려움에서 시간이 지날수록 자주 일어납니다. 증거 훼손(조사 2턴), 방 잠김, 용의자 침묵, 경찰 조기 도착.
- **경찰 도착 턴**: 쉬움 30턴, 보통 35턴, 어려움 45턴.
- **동료 탐정**: 보통·어려움에서 법의학 탐정 윤도경이 수사 초반(행동 3번 뒤) 알아서 시신을 감식하고, 훼방이 시작되면 단서를 찾아 줍니다. 견습 탐정 서하루는 수상한 진술을 귀띔합니다. 어려움에서는 베테랑 탐정 강무열(잠긴 문 열기·시간 벌기)도 나옵니다.
- **탐정 출동**: 장소 화면에서 탐정을 보내면 그 장소를 대신 조사해 2턴 뒤 알려 줍니다(턴 소모 없음, 잠긴 방 가능). 보통은 윤도경·서하루가 2번씩(모두 4번), 어려움은 세 명이 3번씩, 쉬움은 없음.
- **반박 탐정**: 들은 말 아래 ‘반박’을 누르면 프로파일러 한서진이나 심리 탐정 모은재가 대신 따져 줍니다. 거짓말이면 진술이 무너지고, 사실이면 사실이라고 알려 줍니다(턴 소모 없음). 보통은 프로파일러 1번·심리 탐정 2번, 어려움은 2번·2번, 쉬움은 없음.
- **변호사 차도율**: 용의자가 변호사를 기다리며 입을 닫으면 불러서 바로 다시 말하게 할 수 있습니다(턴 소모 없음). 보통 2번, 어려움 3번, 쉬움은 없음.
- **범인 편(보통·어려움)**: 변수 인물 2명이 무작위로 나오고, 그중 한 명은 증거를 망치고 문을 잠그는 공범입니다. 현장 흔적과 비교해 공범을 잡으면 훼손·잠금이 멈춥니다(틀리면 −2턴, 성공 +4점).
- 범인 · 동기 · 수법 · 결정적 증거(최대 3개)를 지목하면 S~F 등급이 매겨집니다.

## 얼굴 그림

그림 파일 없이 코드(SVG)로 사람 얼굴을 그립니다. 이름마다 머리 모양·안경·모자·수염·옷이 정해져서 같은 이름은 늘 같은 얼굴이고, 무작위 사건의 새 인물도 자동으로 얼굴이 생깁니다. 수사팀 6명은 특징을 따로 정해 두었습니다.

## 소리

음악 파일 없이 브라우저의 Web Audio로 빗소리, 낮은 긴장 음, 단서·모순·훼방·사이렌 효과음을 만듭니다. 남은 턴이 6 이하가 되면 심장 박동이 들립니다. 화면의 "소리" 버튼으로 끌 수 있습니다.

## 사건 추가하기

고정 사건은 `index.html`의 `CASES` 배열에, 무작위 사건 재료는 `SETTINGS`·`TRAITS`·`MOTIVE_POOL`·`METHOD_POOL`에 추가하면 됩니다.
