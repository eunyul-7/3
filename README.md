# 한밤의 사건 파일

브라우저에서 바로 플레이하는 텍스트 추리 게임입니다. `index.html`을 열면 시작됩니다. 빌드나 설치는 필요 없습니다.

## 사건

| 파일 | 사건 | 무대 |
| --- | --- | --- |
| 01 | 청람장 사건 | 폭우 속 산장, 서재의 독살 |
| 02 | 달빛극장 사건 | 소극장 인터미션, 분장실 |
| 03 | 은하 야간열차 사건 | 침대열차의 밀실 |
| 04 | 한빛 박물관 매병 사건 | 폐관 후 바꿔치기된 국보 |

사건마다 범인·동기·수법이 모두 다릅니다. 사건을 끝내면 아직 풀지 않은 다음 사건으로 넘어가고, 해결 기록(최고 등급)은 브라우저에 저장됩니다.

## 규칙

- 장소 조사·심문 한 번에 1턴이 지나고, 턴이 다 떨어지면 경찰이 도착합니다.
- 단서를 찾으면 용의자에게 새 질문이 열립니다.
- **모순 지적**: 들은 진술에 단서를 들이밀 수 있습니다. 맞으면 진술이 번복되고 숨긴 사실과 새 시간표 항목이 나옵니다. 틀리면 1턴을 잃고 점수가 깎입니다. 범인이 아닌 사람도 각자 감추는 것이 있습니다.
- 범인 · 동기 · 수법 · 결정적 증거(최대 3개)를 지목하면 S~F 등급이 매겨집니다.

## 사건 추가하기

`index.html` 스크립트 상단의 `CASES` 배열에 객체를 하나 더 넣으면 됩니다. 각 질문에 `need`(열리는 조건 단서), `lie`(모순 단서 목록과 번복 진술), `tl`(시간표 기록)을 붙일 수 있습니다.
