# 청람장 사건

브라우저에서 바로 플레이하는 텍스트 추리 게임입니다. `index.html`을 열면 시작됩니다. 빌드나 설치는 필요 없습니다.

- 폭우로 고립된 산장에서 한도윤 회장이 서재에서 숨진 채 발견됩니다.
- 장소 조사·심문 한 번마다 1턴이 지나고, 28턴이 지나면 경찰이 도착합니다.
- 단서를 찾으면 용의자에게 새 질문이 열립니다.
- 범인 · 동기 · 수법 · 결정적 증거(최대 3개)를 지목하면 등급(S~F)이 매겨집니다.

사건 데이터(`CLUES`, `ROOMS`, `SUSPECTS`, `ANSWER`)는 `index.html` 스크립트 상단에 모여 있어 새 사건으로 바꾸기 쉽습니다.
